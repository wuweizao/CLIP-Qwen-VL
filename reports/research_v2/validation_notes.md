# 核验记录：基础模型与三种 SFT 的确认集对照

核验日期：2026-10-25。结论为**已核验范围内可附条件分享**。本记录属于研究构建过程中的标准核验，不是整个课题完成声明。

## 范围与独立计算

核验基础模型及 plain/retrieval/noise 三种 SFT 的优化随机种子 42、43、44，在 256 张固定确认图像上的 none/random/image/adaptive 四种条件，共 40 个评估、10240 条预测。其中基础模型与 plain 的 4096 条已在前一轮核验，随后独立核验 retrieval/noise 的 6144 条；复用已核验记录进行三种子配对比较。输入为 `outputs/research_v2/evaluations/<model>/test_<mode>_full/predictions.jsonl` 及同目录指标、身份文件；参考答案以 `data/research_v2/test.jsonl` 前 256 条为准。

独立计算没有调用项目指标函数：使用大小写无关的 `[a-z0-9]+` 分词和词频计数，对每个参考答案计算 `2×重合词频数/(预测词数+参考词数)`，取同一图像各参考答案的最大值，再对图像求平均。空串边界按既有协议处理。训练种子标准差使用样本标准差，分母为 `n−1`。

- 两轮合计 10240 条逐图 Token-F1 与保存值的最大绝对差均为 **0**。
- 40 组均值与其汇总指标一致；三种方案的 12 组三种子均值/标准差与 `seed_summary.csv` 一致。三个方案的 36/36 个主对照均已有完整预测；此结论不涵盖辅助实验或外部基准的完成状态。
- 所有确认条件均有相同、唯一且顺序一致的 256 个图像 ID；保存的参考答案与数据清单逐条一致。
- 确认图像没有与第一阶段 64 张探索图像或训练池发生完全相同内容 ID 的重叠；上下文 ID 均属于训练池且不是当前图像。

## 训练和验证控制

九个 SFT 运行的监督图像集合完全相同，各有 128 张图像、128 条指令、32 个优化步、256 个监督微批次；记录到的实际独立监督图像数均为 128。九个运行的验证选定 checkpoint 均为 `checkpoint-32`。没有把数据池大小代替实际训练覆盖数。

每个运行的 checkpoint 选择使用 64 张验证图像；门控阈值另用 64 张验证图像。两组 ID 互不重叠，也均不属于确认集。生成提示词读取图片与训练池上下文，参考答案只用于生成后的评分。数据清单和运行身份文件是这些控制的依据；结果表不是独立的数据来源。

## 解释边界与未核验项

- 普通 SFT 无检索条件相对基础模型的 Token-F1 均值提高 **0.05914937**。独立重算的输出词数从 **15.67968750** 降为三种子均值 **9.97656250**。输出变短与词汇分数提升同时出现，不能据此断言二者存在因果关系。
- 已保存的 CLIPScore 从基础模型的 **0.84358796** 降至普通 SFT 三种子均值 **0.80151227**；本次只核对其报告含义，没有重新执行图像编码。指标方向不一致，因此不能把词汇指标提高写成视觉事实正确性提高。
- 自适应检索在普通 SFT 上优于固定 Top-K 的词汇分数，但其均值仍略低于无检索条件；不能据此宣称它普遍优于不使用检索。
- 训练随机种子 SD 与按图像 bootstrap 的区间含义不同。没有把多个训练种子的同一图像当作相互独立的新图像，也不将图像区间解释为训练随机性区间。
- CIDEr 采用固定训练参考文档频率和项目分词协议；不是可直接与 COCO 排行榜比较的官方完整协议。上下文复制率和参考词覆盖率均为词汇代理，不是幻觉率或人工事实正确性。
- 主实验核验认证基础模型与九个 SFT 主模型在固定确认集上上述词汇指标和控制的完整性；辅助、外部和补充条件另按下方明确范围列出，不扩大为未列明指标或条件的独立核验。人工核验与盲评仍为 pending，未生成替代的人类标签。
- 云端 CI 的执行受账户运行条件限制；本地测试结果与这里的独立数学核验是两类证据，不能互相替代。

六个已完成条件的另外 1536 条逐图 Token-F1 独立重算无差异。三个优化随机种子使用同一组 32 张图像，与随机 128 图像组为嵌套子集；两种预算也使用完全相同的 32 张图像。

## 增量核验：语言 LoRA 加 merger 全参数训练

优化种子 42 的该条件使用同一组 128 张图像、128 条指令、256 个监督微批次、32 个优化步，实际独立监督图像为 128，验证选中的 checkpoint 为 32。256 条确认预测的 Token-F1 独立重算一致，均值为 **0.58015350**。

实际 adapter 文件的 CPU header 检查确认 `modules_to_save=["merger"]`，五个 merger 张量均存在；保存的总参数数量为 **40,395,008**，与训练元数据一致。这里训练完整 merger，而不是在 merger 上新增同秩 LoRA；与仅语言 LoRA 的 3,686,400 个参数相比，训练容量也改变了，不能仅将差值归于微调位置。

同种子、仅语言 LoRA 基线为 0.57440911，差值为 +0.00574439；这只是单个种子的词汇指标比较，不是视觉事实正确性的证明。至此，15 个辅助完整评估的 3840 条逐图 Token-F1 均已独立核验无差异，结合主实验累计为 **14080 条**。这项累计不包括验证集、其他诊断条件及补充记忆库对照；外部结果另在下节核验。

## 增量核验：官方外部诊断子集

四个模型（基础模型与优化种子 42 的 plain/retrieval/noise）的 12 项外部结果均已有完整输出。核验将预测逐条与 `data/research_v2/pope.jsonl`、`sugarcrepe.jsonl`、`transfer.jsonl` 对齐，不调用项目的解析或汇总函数，独立按冻结的首答案规则解析 yes/no 与 A/B，重算混淆矩阵、Accuracy、Precision、Recall、F1、macro-F1、yes 比例、无效率，以及 SugarCrepe 各类型准确率。

- POPE：每模型 360 个问题、20 张图像；三个变体各 120 问、60 yes/60 no，同一组 20 张图像。1440 条问题输出全部对齐官方源标签及问题，所有模型无效回答数为零。
- SugarCrepe：每模型 112 对描述、108 张图像；七种类型各 16 对，正例在 A/B 位置各 8 次。448 条选择输出全部对齐原始正负描述和选项位置，各模型无效回答数均为零。CLIP 保存的相似度按正例大于负例重新比较，均为 87/112（0.77678571），精确平分为零；本次没有重新执行 CLIP 图像编码。
- 迁移描述：每模型 108 张图像，对另 432 条逐图 Token-F1 使用独立词频公式重算，均无差异。结合前面固定确认条件，独立核验的描述 F1 累计为 **14512 条**。
- 12 项结果与各自 `metrics.json` 以及公开的 `reports/research_v2/benchmark_summaries/` 完全一致；不把不同任务预测数相加后解释为独立图像样本数。

## 增量核验：补充库规模控制与基础模型图片打乱

本节分开核验两个独立协议，没有把基础模型图片打乱纳入检索库效应：

- `bank_size_control_protocol.json`：四个固定模型 × 两个推理检索库，各 64 张固定诊断图像，共八个条件、512 条预测。
- `baseline_shuffle_protocol.json`：基础模型的 none/image 两种上下文条件，固定同一批 64 张图像作循环移位，共两个条件、128 条预测。

640 条预测的 Token-F1 独立重算均与逐图保存值和均值一致。逐条检查引用答案仍对应原图像；打乱条件的实际输入图像 ID 确为固定序列的下一张，检索描述仍对应原查询、none 条件为空，未改变标签。

对于库规模控制，独立从原有 full/subset 上下文计算每个查询、每个排序位置的最小词数，确认实际描述均为相应原文前缀，来源 ID、排序、检索分数和截断元数据保留；未引入填充描述，来源均属于相应的训练库且不是查询图像。两库平均上下文词数均为 **15.375**，但实际平均上下文 BPE token 数为 full **17.6875**、subset **16.921875**，因此这里只是词数匹配。
