# 研究第二阶段：预先固定的实验协议

制定日期：2026-10-25。第一阶段的 64 张测试图像只作为探索材料，不进入本阶段确认测试集。主协议初稿在第二阶段模型评估前写入本地项目；它不是独立注册平台的预注册记录。后续修订单独说明，不将修订内容当作最初版本。

## 问题与假设

1. 检索描述的相关性下降是否降低生成质量、增加上下文词汇复制？
2. 在训练中加入检索上下文，能否减轻推理输入形式变化造成的退化？
3. 验证集选择的检索使用阈值与混合噪声训练，能否改善固定 Top-K 的效果？
4. 词汇指标的提升是否伴随图文一致性、事实正确性和细节覆盖的改善？

这些是假设，结果可以不支持它们。检索噪声并非新提出的问题；本实验研究其与小样本 Qwen-VL 适配的交互。

## 数据与预算

- 固定 Flickr8k 数据版本，创建独立的 `data/research_v2`，保留第一阶段数据与权重。
- 从官方训练集建立 1024 图像训练池，从验证集取 128 图像；新测试集取 512 图像并排除第一阶段 64 图像。前 256 张为本轮确认集，其余为保留测试材料，不据其结果选阈值。
- 主实验固定 128 图像微调预算、每图 1 条描述、2 轮；三个优化随机种子为 42/43/44。数据子集与检索上下文固定，使训练随机性可以单独比较。
- 所有主实验使用相同 LoRA 容量、学习率、图像分辨率、更新步数及生成预算。训练数据量/更新步数、检索库规模、采样策略的扩展比较独立标记，不混入主比较。
- 等步数比较匹配优化更新次数与微批量，不等同于严格相同的 token 数或 FLOPs。实际执行步数与验证选出的 checkpoint 步数分别记录。
- 验证集前 64 张仅选择检索门控阈值，后 64 张用于 checkpoint 验证损失选模，两组互斥。本项在第二阶段首次 LoRA 训练前固定。
- 同图的全部描述作为一个单位排除；像素哈希防止完全重复。近重复审查另行记录，不能据此声称排除了基础模型预训练污染。
- 数据效率的覆盖采样使用固定标签词表与 CLIP 特征推断，不读取候选池人工描述来选样；与随机和多样性采样比较时，实际监督标签预算保持一致。检索训练另可访问标注记忆库，其总可访问描述量并不等于普通 SFT，不能将训练方案差异完全归因于输入格式。

## 主实验与诊断

三个训练方案：普通 SFT、检索上下文 SFT、相关/部分相关/随机/无上下文混合训练。三种方案均不接触确认集标签。

每个模型比较无上下文、随机上下文、CLIP 图像检索 Top-K、自适应使用检索。种子 42 额外比较部分相关、合成冲突、描述检索与重排序。上下文数量固定为 2，同一查询的非空诊断条件按词数匹配；记录实际 token 数与生成长度，不声称词数匹配等于 token 数完全一致。

训练检索必须排除当前图像及其全部描述。自适应检索仅根据验证集中 plain 与 Top-K 的配对输出选择分数阈值；先固定策略，再执行确认集推理。CLIP 相似度是决策特征，不被解释成校准后的正确概率。

随机/部分相关/合成冲突上下文都是可复现干预，不是假定经过人工核验的错误信息。人工相关性核验组必须有真实人工标签后才报告。

图像检索使用候选图像的第一条描述；描述检索和图文加权重排可访问训练图像的全部描述，再按图像去重取 K 条。因此图像数相同不等于描述候选数相同，该诊断比较是两套完整检索方案的条件效应，不是固定描述候选数下的纯算法消融。

## 指标与统计

- Token-F1、ROUGE-L、固定训练参考文档频率的 CIDEr 变体、CLIPScore、输出词数、参考细节词覆盖率、上下文内容词复制率。
- 词汇复制率与参考词覆盖率都是代理指标，不解释成幻觉率或事实准确率。CLIPScore 也不作为唯一质量裁判。
- 相同图像配对比较；报告图像 bootstrap 区间和三个训练种子的均值/标准差，两类不确定性分别呈现。
- 图像打乱对照：仅改变图片，保持问题、上下文、参考答案与预算不变。
- 使用独立 POPE 子集检查物体存在性；固定答案解析，明确无效答案处理和 yes/no 平衡。SugarCrepe 子集按类型报告，不冒充全量基准。
- 人工盲评导出匿名材料，评分与解盲映射分离。没有人工评分时状态为 pending，不以模型判断冒充人工结果。

## 交付与解释边界

运行配置、逐样本预测、每个 adapter 的数据清单/步数/参数量、验证阈值记录、运行时间与显存、完整性检查和图表均保留。只在运行成功且核验通过后将其列为 completed。跨数据集和微调位置扩展独立列出；未运行或未完成人工评估的项目明确说明。

连接模块扩展采用语言 LoRA 加视觉 merger 全参数训练，通过 PEFT 的 modules_to_save 保存 merger，并非对 merger 再加同秩 LoRA；它增加可训练参数，不作为参数量匹配的模块位置因果实验。千张候选池的等步数组可能只实际监督其中部分图像，必须报告实际访问的唯一图像数。跨来源子集也不等于未经基础模型预训练见过的数据。

## 方法来源

- [检索增强图像描述的鲁棒性分析](https://arxiv.org/abs/2406.02265)：作为机制研究的已有工作，不宣称首次发现检索干扰。
- [CIDEr](https://arxiv.org/abs/1411.5726) 与 [COCO 参考实现](https://github.com/tylin/coco-caption)：本项目另行明确固定 DF/regex 的实现协议。
- [CLIPScore](https://arxiv.org/abs/2104.08718)：作为图文一致性辅助分数。
- [POPE](https://arxiv.org/abs/2305.10355) 与 [SugarCrepe](https://arxiv.org/abs/2306.14610)：使用固定官方子集，分别检查物体存在性与描述组合语义。

## 修订记录

- 在首次第二阶段 SFT 训练前，将 checkpoint 选模与门控阈值选择分别分配给验证集的后/前 64 张图像。
- 在主实验运行期间、任何覆盖采样辅助模型训练前，审查发现读取整个人工描述池会破坏等标注预算假设，改为不读取人工描述的固定 CLIP 标签特征覆盖。该修订没有根据覆盖采样的测试结果选方法。
- 另设严格词数匹配的记忆库规模补充诊断，使用独立协议和结果文件；它作为方法审查后的补充分析，不包装成原始确认检验。
