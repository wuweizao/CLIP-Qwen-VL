# 简历与面试说明

以下表述依据本机实际运行结果。指标仅适用于固定的 Flickr8k 小规模子集，不等同于全量基准。

## 当前已验证的表述

**基于 CLIP 与 Qwen-VL 的图文检索及多模态微调研究**

- 使用 Flickr8k 构建图像级隔离的训练、验证与测试子集，将人工图像描述转换为 256 条多模态 instruction。
- 实现 CLIP 双向图文检索、训练集检索增强与可复现评测；在 64 图像/320 描述的小候选池中，image→text、text→image 的 Recall@1 分别为 93.75% 和 83.44%。
- 实现 Qwen2.5-VL 的 PEFT LoRA 训练、仅回答部分参与损失的标签掩码、批量推理和实验报告生成流程。
- 在单张 16GB GPU 上完成 Qwen2.5-VL-3B 的 LoRA 指令微调，仅训练约 369 万参数；简洁提示词、无检索条件下，Token-F1 从 0.4877 提升至 0.5711，ROUGE-L 从 0.4628 提升至 0.5566。
- 完成 12 组 Prompt/样本比例/检索增强消融及 768 条预测，使用图像级配对 bootstrap 量化不确定性，发现检索增强在充分微调后可能降低词汇重合指标。

## 精简简历版

基于 CLIP 与 Qwen2.5-VL-3B 构建图文检索及多模态 LoRA 微调流水线，将 Flickr8k 人工描述转换为 256 条指令，在 RTX 5070 Ti 16GB 上完成 12 组消融实验。针对 64 张独立测试图像，主设置下 Token-F1 从 0.4877 提升至 0.5711；实现数据隔离、assistant-only loss、adapter 保存、自动评测与可复现实验报告。

## 面试时应讲清楚

1. Recall@K 的多正例如何定义，为什么 64 张候选图像的结果不能与全量基准直接比较。
2. 同一图像的多条描述为什么必须一起划分；RAG 为什么只能访问训练集。
3. 图像 tokens、用户提示和 padding 为什么不应纳入监督损失。
4. 小样本微调可能改变输出风格，而不代表视觉理解能力提高；词汇重合指标也无法证明没有幻觉。
5. 25% 与 100% 两组固定训练轮数，更新步数不同；该对比不是严格的等计算预算实验。
