# 简历与面试说明

以下推荐表述采用研究 v2 已完成的实验。主对照、辅助扩展和外部子集分别计量，指标不等同于全量基准；人工评分按用户选择延后，不计为已完成。详细依据见 [v2 实验报告](research_v2/results.md) 与 [实验协议](research_v2/protocol.md)。

## 推荐简历表述：研究 v2

**基于 CLIP 与 Qwen-VL 的检索干扰及小样本多模态微调研究**

- 在单张 RTX 5070 Ti 16GB 上实现 Qwen2.5-VL-3B 的 PEFT LoRA 微调，设计普通 SFT、检索上下文 SFT、混合噪声训练三种方案；固定 128 张图像、每图一条监督描述，在三个训练随机种子下完成 36 组主对照，每组评估 256 张未进入前期探索的新确认图像。
- 构建排除同图全部描述的训练集检索、验证集专用的自适应检索阈值选择、图像打乱与受控上下文干预；保存逐样本预测、数据/权重哈希、实际训练步数、显存与断点续跑记录，实现可复现实验审计。
- 量化检索增强的适用边界：普通 SFT 加入固定 Top-K 后，Token-F1 在三个种子上平均下降 1.72 个百分点；验证集选择的自适应检索相对固定 Top-K 平均恢复 1.61 个百分点，但未显示超过无检索基线的证据。报告图像配对 bootstrap 区间和训练种子标准差，避免仅凭单次最好分数下结论。
- 完成选样、等轮数/等步数、千张图像和语言 LoRA 加 merger 全参数训练等扩展，共保存 24 个 v2 adapter；在 POPE、SugarCrepe 和跨来源描述子集上完成四个模型的 12 项外部任务评估，并通过词数匹配的检索库对照及图片打乱检查结果边界。外部任务未出现一致准确率提升，不将词汇收益表述为通用视觉能力改善。

## 精简简历版

基于 CLIP 与 Qwen2.5-VL-3B 构建可复现的多模态检索干扰研究流水线，在单张 16GB GPU 上以 128 张图像完成三种 LoRA 训练方案、三个随机种子及 36 组主对照，使用 256 张新确认图像评测。量化固定检索引起的 Token-F1 平均下降 1.72 个百分点，并验证仅在验证集选阈值的自适应策略可缓解退化；实现数据隔离、回答标签屏蔽、多指标评估与图像配对统计。

## 面试中的研究结论与边界

1. **问题如何从工程实验演化为研究？** v1 的单次小样本结果提示“微调后 RAG 可能降分”；v2 固定数据和训练预算，比较训练时是否接触检索、推理时采用何种上下文，并增加三个训练随机种子。36 组为三种训练方案 × 三个种子 × 四种上下文条件，基础模型 zero-shot 对照另行报告。
2. **具体发现是什么？** 普通 SFT 的无检索、固定检索、自适应检索 Token-F1 均值分别为 0.5766、0.5593、0.5754。自适应策略相对固定检索缓解退化；不能写成“RAG 始终有效”或“已提升通用视觉能力”。训练中加入检索也未消除推理检索的负效应，现有结果不能唯一归因于输入格式变化或检索噪声。
3. **为什么这仍是小样本适配？** 主模型只用 128 条监督答案更新参数，但另有 1024 图像训练池构成的标注检索记忆库。监督答案数量、候选图像数量和可访问描述数量是不同预算；带检索的训练额外访问记忆描述，不能把方案差异当成仅改变输入格式的纯因果实验。
4. **如何避免数据泄漏和反复查看测试集？** v1 的 64 张图像仅保留为探索集，不进入新确认集；训练检索排除当前图像的全部描述。验证集分为互斥的 checkpoint 选模和检索阈值选择部分；确认集结果不参与阈值选择。像素去重和近重复标记不等于证明基础模型从未见过这些图片。
5. **不确定性如何解释？** 图像 bootstrap 区间描述固定训练运行下确认图像的抽样波动，三个种子的标准差描述优化随机性；二者不能相互替代。同一确认图像在多个条件中重复使用，不等于拥有更多独立测试图像。
6. **为什么增加多种指标？** Token-F1 与 ROUGE-L 衡量词汇重合，输出更短或更符合数据集文风也会改变分数。固定训练 DF/regex 的 CIDEr 变体不直接对标 COCO 排行榜；CLIPScore 是同一表征体系下的辅助证据，词汇复制与参考词覆盖也是代理指标。尚无人工标签时，不声称事实准确率、人工偏好或幻觉率得到改善。
7. **预算控制和创新表述如何把握？** 主实验匹配更新步数、微批量、LoRA 容量与生成预算，词数匹配不等于完全匹配 tokens 或 FLOPs。检索干扰已有先行研究，本项目贡献表述为受控复现、适用边界分析及自适应策略验证，不宣称首次发现该问题或取得领先基准成绩。
